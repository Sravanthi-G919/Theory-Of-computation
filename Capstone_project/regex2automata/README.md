# Regex2Automata — Regular Expression to Finite Automata Converter and Visualizer

## Project setup
1. Install Node.js LTS from https://nodejs.org
2. Extract this ZIP.
3. Open the `regex2automata` folder in VS Code.
4. In Terminal run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL shown in the terminal (usually http://localhost:5173).

## Planned conversion stages
- Regex input and validation
- Explicit concatenation and postfix conversion
- Thompson's construction (NFA)
- Subset construction (DFA)
- Graph visualization
- String acceptance tester

This is a starter scaffold. The conversion algorithms will be implemented in later steps.
